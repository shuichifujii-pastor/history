# 歴史人名辞典

紀元後の **西洋史** と **日本史** の人物を調べて、カードとクイズで覚えるためのブラウザアプリです。
インストール不要・サーバー不要で、GitHub Pages にそのまま公開できます。

## 機能

| 画面 | できること |
| --- | --- |
| 辞典 | 人名・よみ・キーワードでの検索（ひらがな／カタカナどちらでも可）、地域・時代・分野での絞り込み、年代順／五十音順／苦手な順の並べ替え、「きょうの人物」 |
| 人物の詳細 | 生没年・要約・キーワード、**くわしい解説**、**生きた時代の出来事**、**同じころの日本／西洋の人物**、お気に入り（★）、自分用メモ |
| 年表 | 年代順に、西洋・日本（選べば**中国**も）の**大きな出来事**と人物（生まれた年）を並べた比較年表。世紀ごとの移動もできます |
| 出来事の詳細 | 年表の出来事を押すと開く。くわしい解説、**背景とその後**、**関係する人物**、**つながりのある出来事**、同じ地域の前後の流れ、同じころのほかの地域、そのころ生きていた人物。「← 戻る」でたどった順に戻れます |
| カード | フラッシュカード（人名→説明／説明→人名）。「覚えた／もう一度」で自己評価 |
| クイズ | 4択クイズ：説明から人物、人物から関連事項、活躍した時代、どちらが先に生まれたか、ミックス |
| 記録 | 正答率・連続学習日数・時代別の定着度・苦手リスト、学習記録の書き出し／読み込み／リセット |

学習記録は「ライトナー方式」で管理しています。正解すると箱が1つ上がり、間違えると2つ下がります。
カードやクイズでは **苦手な人物・未学習の人物ほど出題されやすく** なります。

学習記録・お気に入り・メモはブラウザの `localStorage` に保存されます。
「記録」画面で Google アカウントにログインすると、Firebase（Cloud Firestore）を通して
**同じアカウントでログインしたほかの端末と自動的に共有**されます（下記「端末間の同期の設定」）。
ログインしなければ、これまでどおり端末の中だけで動き、外部には何も送信されません。

## 端末間の同期の設定（Firebase）

1回だけ、Firebase コンソール（https://console.firebase.google.com/ ）で次の設定をします。

1. **ウェブアプリの設定値を入れる**
   ⚙「プロジェクトの設定」→「マイアプリ」でウェブアプリ（`</>`）を選び（なければ追加し）、
   表示される `firebaseConfig` の中身を [`js/firebase-config.js`](js/firebase-config.js) の `null` の代わりに貼り付けます。
   この値は公開されても問題のないもので、データの保護は次の4のルールで行います。
2. **Google ログインを有効にする**
   「Authentication」→「Sign-in method」→「Google」を有効にします。
3. **このサイトのドメインを許可する**
   「Authentication」→「設定」→「承認済みドメイン」に `shuichifujii-pastor.github.io` を追加します。
4. **Firestore を用意してルールを追加する**
   「Firestore Database」を作成し（まだの場合）、「ルール」に次の `match` ブロックを追加して公開します。
   ほかのアプリのルールがすでにある場合は、消さずにこのブロックを書き足してください。

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       // 歴史人名辞典：本人だけが自分の学習記録を読み書きできる
       match /jinmeiProgress/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

しくみ：ログイン中のユーザーごとに `jinmeiProgress/{ユーザーID}` に記録を1件保存します。
各端末の記録とクラウドの記録は、人物ごと・お気に入りごと・メモごとに「新しい方」を採用して統合するので、
オフラインで学習した分も、次にネットにつながったときに失われずに合わさります。
「すべてリセット」はログイン中のすべての端末に反映されます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例：`jinmei-jiten`）。
2. このフォルダの中身をプッシュします。

   ```bash
   git remote add origin https://github.com/<あなたのユーザー名>/jinmei-jiten.git
   git push -u origin main
   ```

3. GitHub のリポジトリ画面で **Settings → Pages** を開き、
   **Source: Deploy from a branch**、**Branch: `main` / `/ (root)`** を選んで Save。
4. 1〜2分後に `https://<あなたのユーザー名>.github.io/jinmei-jiten/` で使えるようになります。

## 手元で試す

`index.html` を直接開くと、ブラウザによってはスクリプトが読み込めないことがあります。
その場合はこのフォルダで次を実行し、`http://localhost:8765` を開いてください。

```bash
python -m http.server 8765
```

## 人物を追加・修正する

人物データは [`js/data.js`](js/data.js) にあります。ファイル冒頭の説明どおりに書き足すだけで、
辞典・年表・カード・クイズのすべてに反映されます。

```js
{ name: "人名", sub: "よみ または 原語", region: "日本", era: "江戸", cat: "政治", born: 1700, died: 1770,
  desc: "説明文（本人の名前は書かない）", keys: ["キーワード1", "キーワード2"] },
```

- `name` は学習記録のキーなので、一度公開した後は変えないでください。
- 説明文 `desc` はクイズの問題文にもなるため、本人の名前を含めないようにしてください。
- 生没年に諸説ある場合は `life: "1412頃–1431"` のように表示用の文字列を指定できます。
- 詳しい解説は [`js/details-west.js`](js/details-west.js)・[`js/details-japan.js`](js/details-japan.js) に、`"人名": "解説文",` の形で書きます。
- 年表の出来事は [`js/events.js`](js/events.js) に `{ y: 1517, r: "西洋", t: "出来事" },` の形で書き足せます（中国は [`js/events-china.js`](js/events-china.js) に `r: "中国"` で）。
- 1900年代以降の人物は [`js/people-modern.js`](js/people-modern.js) にあり、詳しい解説も `detail` に一緒に書いています。存命の人物は `died: null` にします。

ファイルを更新して公開するときは、`index.html` にある `?v=8` などの版数をすべて1つ上げてください。
ブラウザが古いファイルを使い続けるのを防げます。

## ファイル構成

```
index.html             画面の骨組み
css/style.css          デザイン（明るい表示が基本、🌙ボタンで暗い表示、スマホ対応）
js/data.js             人物データ（196人、クイズに使う要約）
js/people-modern.js    1900年代以降の人物（65人、解説つき）
js/details-west.js     人物の詳しい解説（西洋）
js/details-japan.js    人物の詳しい解説（日本）
js/events.js           年表の大きな出来事（西洋・日本 約210件）
js/events-china.js     年表の中国の出来事（約80件）
js/event-details.js    出来事の詳しい解説とつながり（「地域:年」をキーに記入。人名は自動でリンク）
js/event-more-*.js     出来事の「背景とその後」（西洋・日本・中国の3ファイル）
js/app.js              アプリ本体（辞典・年表・カード・クイズ・記録）
js/firebase-config.js  Firebase の設定値（同期を使うときに記入）
js/sync.js             端末間の同期（Google ログイン + Firestore）
manifest.webmanifest   ホーム画面に追加したときの名前・アイコン
icons/                 アプリのアイコン画像（ホーム画面・ブラウザのタブ）
```

## スマホのホーム画面に追加する

- **iPhone（Safari）**：画面下の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
- **Android（Chrome）**：右上の「︙」→「ホーム画面に追加」→「追加」

ホーム画面には「人名辞典」という名前でアイコンが並びます。開くと、いつものブラウザでアプリが表示されます
（ログインと同期をブラウザと共通にするため）。
